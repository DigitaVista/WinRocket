A block theme for competition and prize draw stores built with WooCommerce and Giveaway Lottery (WinRocket).

== Description ==

* Featured competition hero with up to five slides.
* Stats strip: competitions live, entries taken, competitions with instant wins.
* Section links and competition card rows: Featured, Ending soon, Instant wins and any category.
* Competition cards with status badges, closing date, tickets available bar and price.
* Single competition page with info cards (ends, tickets sold, winners, prizes) and stacked sections or tabs.
* Draw results page block.
* Appearance > WinRocket settings: announcement bar, header button, card options, single page sections.
* One-click demo content with sample entries and finished draws (can be removed again).

All theme blocks can be added and edited in Appearance > Editor (category "Theme").
